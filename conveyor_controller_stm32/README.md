# 传送带启停控制板

该STM32F103C8T6工程只负责接收Jetson发出的启停脉冲并控制传送带继电器，与独立报警灯控制板不是同一块硬件。

## 接线与控制逻辑

| Jetson信号 | STM32引脚 | 功能 |
|---|---|---|
| BCM6 / Pin 31 | PA0下拉输入 | 停止传送带 |
| BCM13 / Pin 33 | PA1下拉输入 | 启动传送带 |
| - | PB0推挽输出 | 控制传送带继电器 |

当前继电器控制逻辑：

- PA0收到有效高电平脉冲后，PB0输出低电平，传送带停止；
- PA1收到有效高电平脉冲后，PB0输出高电平，传送带启动；
- PA0、PA1同时有效时，停止命令优先；
- 上电后仍保持原有行为，PB0默认输出高电平。

## 输入消抖与抗干扰

程序使用PA0、PA1上升沿外部中断，并执行两级软件过滤：

- 同一路输入距离上一次有效触发必须超过300 ms，过滤短时间内的重复边沿；
- 进入中断后等待约1～2 ms并再次读取引脚，只有输入仍为高电平才执行命令；
- PA0和PA1分别记录各自的最后有效触发时间；
- PB0在收到命令后保持对应状态，不需要Jetson持续输出高电平。

Jetson当前输出50 ms高电平脉冲，明显长于中断后二次确认所需的约1～2 ms。此版本是现场已验证能够正常启停传送带的基线。此前尝试的1 ms连续采样、连续高15 ms确认方案在实机测试中未能可靠控制传送带，因此已经回退。

软件滤波不能解决供电跌落、STM32复位、输入超过3.3 V或强电磁耦合。两块板必须共地，信号线应远离电机和继电器动力线；现场干扰仍明显时，应在输入端增加合适的RC滤波、施密特触发器或数字隔离，并用示波器确认脉冲幅值和持续时间。

## 工程文件

- `32jidianqi/32jidianqi.ioc`：STM32CubeMX配置；
- `32jidianqi/Core/Src/main.c`：中断回调、300 ms重复触发过滤和继电器控制；
- `32jidianqi/Core/Src/gpio.c`：PA0/PA1上升沿中断和PB0输出初始化；
- `32jidianqi/MDK-ARM/32jidianqi.uvprojx`：Keil工程。

修改后需要重新编译并通过ST-LINK烧录到传送带控制板。烧录前应断开或确保传送带动力回路安全，烧录后依次验证停止、启动、连续高电平不重复执行和启停同时输入时停止优先。
