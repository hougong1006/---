# 传送带启停控制板

该STM32F103C8T6工程只负责接收Jetson发出的启停脉冲并控制传送带继电器，与独立报警灯控制板不是同一块硬件。

## 接线与控制逻辑

| Jetson信号 | STM32引脚 | 功能 |
|---|---|---|
| BCM6 / Pin 31 | PA0下拉输入 | 停止传送带 |
| BCM13 / Pin 33 | PA1下拉输入 | 启动传送带 |
| - | PB0推挽输出 | 控制传送带继电器 |

当前继电器控制逻辑：

- PA0收到有效高电平脉冲后，PB0输出低电平，传送带停止；
- PA1收到有效高电平脉冲后，PB0输出高电平，传送带启动；
- PA0、PA1同时有效时，停止命令优先；
- 上电后仍保持原有行为，PB0默认输出高电平。

## 输入消抖与抗干扰

程序不再使用PA0、PA1外部中断直接驱动继电器，而是由主循环每10 ms定时采样，并执行多级软件过滤：

- 输入连续约60 ms为高电平才确认一次启停命令；
- 命令执行后锁定400 ms，抑制机械臂运动和继电器切换造成的重复触发；
- 输入连续约120 ms回到低电平后才重新武装，确保一个脉冲只执行一次；
- 上电先安全锁定2 s，并要求PA0、PA1双低稳定约120 ms后才接收命令；
- PA0停止与PA1启动同时有效时停止优先，启动前还会再次确认停止输入为低电平；
- PB0在收到命令后保持对应状态，不需要Jetson持续输出高电平。

Jetson当前通过BCM6/BCM13输出150 ms高电平脉冲，为约60 ms的稳定采样确认提供余量。软件滤波不能解决供电跌落、STM32复位、输入超过3.3 V或强电磁耦合等问题。

## 工程文件

- `32jidianqi/32jidianqi.ioc`：STM32CubeMX配置；
- `32jidianqi/Core/Src/main.c`：10 ms定时采样、稳定时间过滤、启动锁定和继电器控制；
- `32jidianqi/Core/Src/gpio.c`：PA0/PA1普通输入和PB0输出初始化；
- `32jidianqi/MDK-ARM/32jidianqi.uvprojx`：Keil工程。

修改后需要重新编译并通过ST-LINK烧录到传送带控制板。烧录前应断开或确保传送带动力回路安全，烧录后依次验证停止、启动、连续高电平不重复执行和启停同时输入时停止优先。
