# SQ 现场手敲清单

现场共输入 7 行，只需打开 `02_机械臂分拣端/yolov11_sortation.py`。

## 第一处：夹爪闭合角度（1 行）

在夹爪参数的预留位置输入：

```python
self.GRIPPER_CLOSED_ANGLE = 165.0
```

讲解：设置夹爪闭合角度，保证夹取工件时具有稳定的夹持力。

## 第二处：坐标转换与补偿（2 行）

在 `do_grasp()` 函数的预留位置输入：

```python
pose_T = self.pixel_to_base(cx, cy, dist)
pose_T += [self.x_offset, self.y_offset, self.z_offset]
```

讲解：将像素位置和深度信息转换为机械臂基座坐标，再叠加三个方向的现场标定补偿。

## 第三处：KDL 逆运动学请求（4 行）

在 `solve_ik_joints()` 函数的预留位置输入前 3 行，并在 `request.roll = -1.0` 下方输入最后 1 行：

```python
request = Kinemarics.Request()
request.tar_x, request.tar_y, request.tar_z = pose_T
request.kin_name = "ik"
future = self.client.call_async(request)
```

讲解：创建 KDL 逆运动学请求，写入目标三维坐标并调用求解服务，得到机械臂各关节的目标角度。
