# SQ 现场手敲清单

现场共输入 10 行，只需打开 `02_机械臂分拣端/yolov11_sortation.py`。

## 第一处：坐标转换与补偿（4 行）

在 `do_grasp()` 函数第 347 行开始输入：

```python
pose_T = self.pixel_to_base(cx, cy, dist)
pose_T[0] += self.x_offset
pose_T[1] += self.y_offset
pose_T[2] += self.z_offset
```

讲解：将像素位置和深度信息转换为机械臂基座坐标，再叠加三个方向的现场标定补偿。

## 第二处：KDL 逆运动学请求（6 行）

在 `solve_ik_joints()` 函数的预留位置输入前 5 行，并在 `request.roll = -1.0` 下方输入最后 1 行：

```python
request = Kinemarics.Request()
request.tar_x = pose_T[0]
request.tar_y = pose_T[1]
request.tar_z = pose_T[2]
request.kin_name = "ik"
future = self.client.call_async(request)
```

讲解：创建 KDL 逆运动学请求，写入目标三维坐标并调用求解服务，得到机械臂各关节的目标角度。
