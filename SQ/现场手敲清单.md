# SQ 现场手敲清单

现场共输入 4 行，只需打开 `02_机械臂分拣端/yolov11_sortation.py`。

## 第一处：夹爪闭合角度（1 行）

在夹爪参数的预留位置输入：

```python
self.GRIPPER_CLOSED_ANGLE = 165.0
```

讲解：设置夹爪闭合角度，保证夹取工件时具有稳定的夹持力。

## 第二处：坐标转换与补偿（2 行）

在 `do_grasp()` 函数的预留位置输入：

```python
pose_T = self.pixel_to_base(cx, cy, dist)
pose_T = self.add_offset(pose_T)
```

讲解：将像素位置和深度信息转换为机械臂基座坐标，再叠加三个方向的现场标定补偿。

## 第三处：KDL 逆运动学请求（1 行）

在 `solve_ik_joints()` 函数的预留位置输入：

```python
future = self.request_ik(pose_T)
```

讲解：提交 KDL 逆运动学请求，计算机械臂各关节的目标角度。
